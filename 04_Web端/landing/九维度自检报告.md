## 一、排版（Typography）

**字体系统**：衬线标题 + 无衬线正文的两族制，五档字重全部走本地子集（`Noto Serif SC 900/700` + `Noto Sans SC 700/500/400`），**零外部请求**。

**实测阶梯**（1440 视口）：

```
h1      146px / 900 / 行高 137.24px   ← 主视觉，负字距 -0.018em
h2       52px / 900 / 行高  59.28px   ← 深色带标题
h2      25px / 900                    ← 分区标题
h3     15.5px / 900 / 行高  25.58px   ← 卡片标题
body     15px / 400 / 行高  24.75px   ← 正文，1.65 行高
small  11.5px / 500                   ← 等宽注解
```

**中文字距的关键判断**：衬线标题不能用拉丁文的负字距（`-0.03em`），会挤掉汉字间的呼吸。中文标题定在 `+0.005em`，主视觉大字才用 `-0.018em`（大字负字距才不散）。

**行长控制**：正文用 `max-width` 而不是 `ch`（中文 `ch` 计算不准）。舒适行长 30–36 全角字，卡在 `30em` 以内。

**避头尾（中文断行规则）**：全页扫描 h1/h2/h3 + 正文段落，检查「行首出现收尾标点」与「行尾出现开引号」两类违规，以及末行孤字。**五档宽度（1440/1280/1024/768/390）全部零违规** —— 浏览器内置的 `line-break: strict` 已正确处理 CJK 避头尾，**不需要手写 `word-break`**。

> **踩过的坑（值得单记）**：深色带标题一度断成「四个动作，一张表出」/「来。格式一个像素没动。」—— 在「出」和「来」之间劈开一个词。
> 我第一反应是用 `max-width: 20ch` 去控，**完全无效**：`ch` 是拉丁字符「0」的宽度，中文一个字≈1em≈**2ch**，所以 `20ch` 实测还有 636px。
> **正解**：把句读点直接写成 `<br>`（「四个动作，一张表出来。」<br>「格式一个像素没动。」）。中文大标题想要精确断句，只有 `<br>` 可靠。
> 顺带把 `.dark h2` 的 `text-wrap:balance` 改成 `pretty` —— `balance` 会为了「两行等高」牺牲断句位置，中文大标题上得不偿失。

**数字等宽**：所有数字列（周次、人次、指标）用 `font-variant-numeric: tabular-nums` —— 中文站里阿拉伯数字不对齐最难忍。

**字体子集的两个致命坑（本轮修复）**：

1. **`unitsPerEm` 必须归一化到 2048**。本机 Noto CJK 可变字体是 1000 upem，且 `fvar` 的 `wght` 默认值是 **200**（ExtraLight）。实例化到 900 后交给 Chromium 光栅化，**横笔画塌成亚像素宽** —— 146px 大字上每条横笔画都有一条极细横线，把「一」「学」「期」拦腰切一刀。
   **修复**：`scale_upem()` 把 upem 等比放大到 2048，轮廓坐标、hmtx/vmtx、head bbox、hhea/OS-2 升降部、post 下划线度量全部同步缩放（实测 ascent 1151→2357，比例 2.048 精确）。
   已逐一排除的无关因素：`desubroutinize` / `notdef_outline` / `recalc_bounds` / `avar` / `gasp` / 是否子集化 / 是否 base64 内联 / `instancer` 的 `optimize`。

2. **`OS/2.usWeightClass` 必须改回真实字重**。源字体是 200，不改的话浏览器会按 ExtraLight 去挑替代字体 —— 字体明明加载了却不生效。

## 二、留白（Whitespace）

八级间距音阶：`8 / 14 / 22 / 34 / 54 / 84 / clamp(88px,12vh,140px)`。

**分区节奏**：`.sec{padding-top: var(--sp-7)}` 统一交给 `clamp(88px, 12vh, 140px)` —— 视口越高留白越大，矮屏不浪费。深色反差带用自己的 `clamp(56px,7vw,92px)`，比浅色区**紧**一档：深色块本身有重量，再给同样留白会显空。

**分区标题的收口**：序号 · 标题 · 右侧注解，靠一条 1.5px 硬线收口，注解与硬线基线对齐。

> **踩过的坑**：`.sec-head` 高度一度是 **318px**（应为 49px），页面上是一块莫名空白。
> 排查了一整轮（`h2` 单行 32.5px ✓ / `idx` 19px ✓ / 注解单行 14px ✓ / `nowrap` 已生效 ✓ / `flex-wrap` ✓ / `clientHeight` 与 `scrollHeight` 三者一致 317/318），
> 真因是**class 名冲突**：`.tail` 同时是「尾屏 section」和「标题右侧注解」。
> 尾屏规则 `.tail{padding:clamp(64px,8vw,110px) 0}` 被继承到注解 span 上，实测 height 194px、`padding-top:110px`。
> **修复**：注解重命名 `.tail` → `.note`；`align-items:baseline` → `flex-end`（`baseline` + `flex-wrap` 也会撑高容器）。
> 结果：**318px → 49px**。

## 三、视觉层级（Visual Hierarchy）

一级（主视觉 146px 衬线）→ 二级（深色带 52px）→ 三级（分区标题 25px）→ 四级（卡片标题 15.5px）→ 五级（正文 15px）→ 六级（等宽注解 11.5px）。

**深色反差带是全页唯一重心**：整页浅纸色，只有 `#121316` 那一段翻转，眼睛自然被吸过去。这是节奏的全页锚点。

**红的使用纪律**：`#B72C24` 全页只出现在「此刻」——
- 主视觉「十八格」和首屏红笔划线
- 学期线上「本周」那一格（W5）
- 阅读进度条
- 卡片引语的左侧 2px 竖线
- 尾屏「交给它」

看板上的「2 / 6 / 18 / 11 / 0」五项指标里，**只有「本周检查人次」是红的**，其余全是墨色。这不是装饰，是信息分级。

**证据卡网格（本轮修复）**：

原用 12 列 span 布局，同一行 `c-main`(726px) 与 `c-side`(512px) 各按自身宽度算 `aspect-ratio`，frame 高 452 vs 319，**行内高差 155px，一眼就散**。

改为**三行 × 两列**的显式轨道（`1.36fr / 1fr` + `align-items:stretch`），行高由该行最高的一张卡驱动，两张卡等高：

```
改前                          改后
行1  c-main 621 / c-side 466  →  613 / 613  ✅
行2  c-third 488 / c-wide 621  →  592 / 592  ✅
行3  c-side(tall) 751 / c-main 600  →  竖版卡改横向独占一行（1260×527）
```

竖版手机截图（4:5）比同排 16:10 卡高出近一半，硬凑一行会把整行拉到 800+，右侧留大片空白。**改为独占一行、图片在左、文字说明在右横向铺开** —— 高图配宽注释，一行照样是满的，并顺势成为「OUTPUT — 最终交付物」的重点展示位（附交付物文件名清单）。

## 四、色彩（Color）

**色板**（`build/tokens.css` 为单一事实源）：

```
纸   #F7F5F0  paper      暖白，不是纯白 —— 纯白在长阅读里发燥
墨   #14151A  ink        冷黑，不是纯黑 —— 与暖纸形成冷暖张力
红   #B72C24  red        压暗的正红，只在浅底上用
亮红 #F05A4C  red-bright 深色带里的红，提亮以补深底吃色
深   #121316  dark       深色带底
线   #DFDAD0  rule       暖灰线，1px
```

**WCAG AA 全通过**：33 处可见文字检测点，最低 **4.74:1**（要求 4.5:1），大字最低 3:1 要求下实测 5.55–5.67:1。

> **踩过的坑**：对比度脚本一度报 `·` 和「学期线」是 1.15:1（假阳性）。
> 原因：顶栏 `color-mix()` 算成 `color(srgb 0.968 0.960 0.941 / 0.88)`，分量是 **0–1 浮点**而非 0–255，被当成 0–255 读出（0.968 → 近黑）。
> **修复**：颜色解析按 `^color\(` 或三分量均 ≤1 判为 srgb 空间并乘 255，并支持半透明层与父背景合成。

**深色带上的红单独处理**：`#B72C24` 在 `#121316` 上只有 3.4:1，不够。深底一律换 `--red-bright: #F05A4C`，实测 5.55:1。

## 五、动效（Motion）

三档缓动：
```
--ease-out   cubic-bezier(0.16, 1, 0.3, 1)    ← 揭示、位置变化（快出慢停）
--ease-soft  cubic-bezier(0.32, 0.72, 0, 1)   ← 按钮红涌入（更柔）
```

| 动效 | 实现 | 时长 |
|---|---|---|
| 滚动揭示 | `translateY(22px)` → 0，`data-d="1/2/3"` 三级延迟 | 0.9s |
| 学期线生长 | 18 格柱子 `scaleY(0→1)`，逐格延迟 `calc(var(--i)*34ms + 220ms)` | 0.85s |
| 首屏红笔 | `scaleX(0→1)`，延迟 0.95s 等标题落位 | 1.1s |
| 阅读进度 | 1px 红线 `scaleX`，`requestAnimationFrame` 节流 | 跟随滚动 |
| 横幅脉冲 | 红点 `box-shadow` 扩散 | 2.6s 循环 |

**「本周」标签的延迟出场**：`animation-delay: 1.5s` —— 等 18 格柱子长完（最后一格 220ms + 17×34ms + 850ms ≈ 1.6s），标签才浮出来。**动效排队，不叠加**。

**减少动态完整降级**：`prefers-reduced-motion: reduce` 下全部动画压到 0.001ms，同时**把终态写死**（柱子 `scaleY(1)`、标签 `opacity:1`、红笔 `scaleX(1)`）—— 内容必须完整可见，不能因为关动效就消失。实测三项均可见。

## 七、响应式（Responsive）

**九档视口零溢出**：320 / 390 / 480 / 768 / 834 / 1024 / 1280 / 1440 / 1920 —— 全部 `hScroll: false`、`overCount: 0`。

**学期线的容器查询**（本轮技术要点）：
```css
.term-cq{container:termline / inline-size}
@container termline (max-width:1180px){ .term-cq .weeks{--wk-w:64px} }
@container termline (max-width: 900px){ .term-cq .weeks{--wk-w:60px} }
@container termline (max-width: 640px){ .term-cq .weeks{--wk-w:56px} }
@container termline (max-width: 420px){ .term-cq .weeks{--wk-w:52px} }
```

> **两个坑**：
> ① `@container` 必须挂在**有确定宽度的内容盒**上。挂在 `<section>` 上时 `clientWidth` 等于视口宽，永远命中不到窄档 —— 必须挂 `.wrap`（宽 = `min(1260px, 100% - 2*gut)`）。
> ② **容器查询不能覆写 `:root` 上的变量**（`:root` 在容器作用域之外），必须用**命名容器** + 容器内选择器。
> 实测 `--wk-w` 随容器宽 1260→1192→938→703→440→354→284 正确变为 64/64/64/60/56/52/52。

**窄屏不压缩 18 格**：宁可横向滚动，也不把格子压到读不清周次。数字可读优先于「一屏放下」。移动端专门写了等宽提示「← 可横向滑动看完全学期 →」。

**触屏与移动的专门处理**：
- ≤720px 隐藏顶栏导航（改由滚动承担），主按钮文字换成「平台 →」省空间
- 「本周」标签在移动端从格子上方移到格内左下角（上方会被顶栏压住）
- 卡片全变单列，间距收一档

## 八、原创性（Originality）

**记忆点：「一学期 = 一条线」**。

质检部的工作是 18 周 × 每周一串固定动作。市面上所有「工作流自动化」落地页都用**流程图**（上传 → 处理 → 下载）。这里不用流程图，用**学期线**：18 个格子横排，已完成的用墨色柱子、本周是唯一一处红、未来是极淡灰、无活动周是斜纹。

这个符号是**从工作本身长出来的**，不是套模板：学生干部一学期就活在「第几周」里。它同时承担：
- 记忆点（一眼记住这个部门在干什么）
- 进度表达（现在走到第 5 周）
- 数据密度（每格挂 tooltip：几活动、几人次检查）
- 状态语义（四态：已检查 / 本周 / 未开始 / 无活动）

**差异检验**：如果把这个页面换成任何其他「表格处理工具」的落地页，学期线立刻失效 —— 它不可移植，所以是原创的。

**证据是真实截图**：6 张卡片全部是与部长、规划部的**真实微信对话截图**，配原话引用（「尽量不要一个学院连续两周都被安排」「不要用文件，发这种格式」）。不是示意图、不是假数据、不是 Lorem ipsum。这是「真在群里跑的对话」，也是这个页面最不可替代的部分。
