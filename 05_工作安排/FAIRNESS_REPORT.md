# 公平性实测报告（50 周确定性模拟）

- 模拟周数：**50** 周
- 助理人数：**17** 人（派活池，领导层只监督不接活）
- 工作内容：**9** 件/周 × 2 校区列 = 18 格

## 长期负载均衡
- 人均累计件数：均值 **52.94** / 标准差 **0.24** / 极差 **1** 件
- 各活忙碌度极差：**0** 件（最忙与最闲的活之间差距）

## 可复现性与健康度
- 单周最大负载：**2** 件/人（全员单周不超 2 件）
- 上周同活重复：**11** 次 / 共 900 格·周

> **确定性保证**：shake=0 时，给定同样的名单任何人跑出完全相同的数字，不依赖 `random`。分配由 sha256(周次|重摇|人员id) 稳定哈希裁决，可审计、可复现。

> **回归门禁**：`_probe_random.py` / `_probe_sortchain.py` 为 CI 公平性门禁（纯 Python、秒级、非零退出即失败）。接入新部门后，本报告的极差 / 标准差应作为新的基线重新采集。
