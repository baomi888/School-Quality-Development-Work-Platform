01三分钟跑起来

第一次用只做三件事，之后每次只要第二件。

  1. 把压缩包解压到硬盘 右键压缩包 → 解压到当前文件夹。得到一个叫「质检部工作安排台」的文件夹。 建议放在 D:\ 或桌面，不要放在 OneDrive / 微信文件缓存目录里（同步会锁文件，容易启动失败）。 如果双击后提示「没有权限」或窗口一闪就没，把整个文件夹挪到 D:\ 下重试。
  2. 双击文件夹里的「启动.bat」 会弹出一个黑窗口，刷几行字。等它出现「就绪」两个字，浏览器会自动打开界面。 这个黑窗口从头到尾不要关——它就是服务本身，关了网页就打不开了。
  3. 用完后关掉黑窗口 直接点黑窗口右上角的 × 就行。下次要用再双击「启动.bat」，数据不会丢。 如果窗口关了网页还打得开，双击一次「停止.bat」收尾。
最常见的翻车点

双击后窗口一闪就没了——多半是杀毒软件（360 / 火绒 / 电脑管家）拦了。把整个文件夹加进白名单，或者把压缩包换台电脑试，再不行截图发我。

02第一次进入：身份与口令

界面第一屏是「部门大厅」，会看到一张「质检部」卡片。点进去会让你选身份，这一步选错了权限就不一样。

你是部长 → 选「管理层」

  • 选择管理层后，会弹出一个口令框，默认口令是 sutuo（素拓的拼音）。
  • 输进去就能进派活工作台，可以改人员、改任务、派活、导出表格。
第一件事：把口令改掉

进到工作台后，找到「修改口令」，把 sutuo 换成只有管理层知道的。默认口令写在程序里，谁拿到这个包都能猜到——这是目前唯一的安全口子。

你不是部长 → 选「小助理」

小助理只需要在下拉里选中自己的名字，进来看到的就是「我本周负责哪几件事」，只读，看不到别人的，也改不了任何东西。

关于口令记住

口令会存在浏览器里，同一台电脑同一个浏览器不用每次输。换电脑、换浏览器（Edge 换 Chrome）要重新输一次。

03两个系统分别管什么

包里其实是两个程序，打包在一起，一次启动同时跑起来。别被两个端口号吓到，你只需要记住「左边管派活，右边管拆表」。

入口它管什么你什么时候用
工作安排台
127.0.0.1:8766		 按校区把活派到人头上，导出官方格式的安排表，看谁这周接了几件活。 周一排这周的活、周五导出表发群。
周工作平台
127.0.0.1:8765		 上传活动登记表总表，拆成西城/官渡两份，安排二级学院、安排检查助理，存台账。 周四处理登记表、周末现场检查后补台账。

怎么进第二个

进「质检部」之后会看到两个大按钮：

  • 工作安排类 —— 就是安排台，派活、导出、台账。
  • 质检部 Web 端 —— 直接把周工作平台嵌在页面里，不用另开浏览器标签。
两个系统的联动

在安排台排好「第 N 周」，回到周工作平台的「排班台账」，每周会有一个「从安排台同步助理」的按钮。点一下，安排台里这周派给谁检查，就会自动填到台账对应周次的活动上——不用两边各填一遍。

04一周标准流程

照着你平时的工作节奏来，一周五次操作，每次两三分钟。

时间做什么在哪个系统
周一 收各学院的空闲时间表，把这一周的活建起来：
派「收集空闲时间表」「安排二级学院检查活动」「安排助理检查活动」等任务，每项分西城 / 官渡两列填人。		 安排台
周二 派「整理邮箱」。顺手在安排台点提交，确认这周的派活结果已经存下来。 安排台
周三 / 周四 派「与规划部交接」；有空档的把「发布值班请假登记表」一并派掉。 安排台
周四 拿到活动登记表总表 → 上传 → 拆分校区 → 勾选二级学院 → 填检查助理。
同时把安排台这周的分配同步回台账。		 周工作平台
周五 导出官方格式的安排表，发交流群。发共享表，不要发文件（防止版本混乱）。 安排台
周末 现场检查完，把实际检查情况补进「排班台账」；错过的活动也在这里补。 周工作平台

周工作平台的四个步骤

  1. 上传总表 —— 拖进本周的活动登记表，系统自动认周次和校区。
  2. 拆分校区 —— 一键拆成西城、官渡两份，原表格式（字体、边框、合并单元格）会保留。
  3. 安排学院 —— 每个活动勾两个检查学院，系统会提示有没有排重、有没有漏排。
  4. 安排助理 —— 填时段和助理，或者直接用安排台同步过来的结果。

每一步的产物都能单独下载，做完会自动出一份表格预览，下载前还会体检一遍。

05小助理怎么用

这里有个必须先说清楚的限制。

现在只能在同一台电脑上用

这套程序跑在「本机」上（127.0.0.1 的意思就是这台电脑自己）。别的电脑、手机，即使连同一个 WiFi 也打不开。所以目前小助理要看自己的任务，只能在你电脑上看，或者由你把安排截图发群。

要让十几个人各自在自己电脑上登录，需要把程序部署到一台服务器上——这是下一步的事，不在这个包里。

如果小助理就在你旁边用这台电脑

  1. 在部门大厅选「小助理」。
  2. 下拉选自己的名字。
  3. 看到的就是这一周自己负责的事，只读。看完选「退出」换下一个人。

06常见问题

双击「启动.bat」，黑窗口一闪就没了
多半被杀毒软件拦了。把整个文件夹加进白名单重试。也可能是解压不完整——重新解压一次，别在压缩包里直接双击运行。
黑窗口开着，但浏览器没自动打开
手动在地址栏输 127.0.0.1:8766 回车。还打不开就看黑窗口里最后几行，有没有「超时」字样。
提示端口被占用 / 页面一直转圈
说明上次没关干净。先双击「停止.bat」，再重新「启动.bat」。还不行就重启电脑，最省事。
用着用着页面白屏，点什么都没反应
黑窗口是不是被关掉了？它是服务本体。重新双击「启动.bat」，然后刷新网页（Ctrl+F5）。
忘记口令了
打开 engine\data\manage_key.txt，里面就是当前口令。如果没有这个文件，说明从来没改过，口令还是默认的 sutuo。把该文件删掉再重启，也会回到默认口令。
数据会不会传到网上？
不会。整套程序只在这台电脑上跑，不联网、不上传、不需要账号。断网也能用。
「智能体」那个页面点进去没反应
它需要额外配置一个模型密钥才能用，属于试验功能，日常派活和拆表都用不到它，暂时忽略。
能发给别人一起用吗？
包本身可以复制给别的部门（他们改自己的人员名单就行），但同一时间只能一人在自己电脑上用，不能多人共享同一份数据。
怎么升级到新版本？
把新的压缩包解压到另一个文件夹，然后把旧文件夹里的 engine\data 和 web4\data 这两个目录复制过去覆盖。这样人员、任务、台账都保留。

07数据与安全

三条必须知道的红线，都不难，但很要命。

一、数据存在哪

目录装什么
engine\data安排台的数据：人员名单、任务清单、每周派活台账、口令
web4\data周工作平台的数据：活动台账、上传过的登记表登记信息、历史归档

备份就是复制这两个文件夹。建议每周五导出完表，顺手把 engine\data 和 web4\data 复制一份到 U 盘或自己的网盘。

二、里面有真实姓名

人员名单里是干事和助理的真实姓名。这个包不要发到大群、不要传公开网盘、不要上传到任何代码仓库。只发管理层。

三、改掉默认口令

默认口令 sutuo 是公开的。第一次进去就改，改完把新口令只告诉管理层。

一句话备忘

两个端口：8766 安排台、8765 周工作平台。两个数据目录：engine\data、web4\data。启动双击 bat，用完关黑窗口。
