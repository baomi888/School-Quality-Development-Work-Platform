质检部 · 工作安排台（免安装）
========================================

★★ 第一次用，只看这一行 ★★
   双击「00-新手引导.html」→ 按里面 01~03 节做，三分钟就能跑起来。
   （双击「启动.bat」后，浏览器也会自动把这份引导打开）

【怎么启动】
1. 把整个文件夹解压到硬盘（建议 D:\ 或桌面，别放网盘同步目录）
   ⚠ 一定要先「全部解压」，不要在压缩包里直接双击，否则会缺文件启动失败
2. 双击「启动.bat」
3. 等黑窗口出现「就绪」，浏览器会自动打开
   - 新手引导   http://127.0.0.1:8765/guide  ← 第一次自动打开这个
   - 安排台     http://127.0.0.1:8766        ← 主入口
   - 周工作平台 http://127.0.0.1:8765

★ 黑窗口不能关，关了服务就停了。用完再关。

【怎么停】
关掉黑窗口即可；若网页仍能打开，双击「停止.bat」收尾。

【默认口令】
sutuo        ← 第一次进去请立刻在「修改口令」里改掉

【数据在哪】
engine\data    安排台：人员、任务、每周派活台账、口令文件 manage_key.txt
web4\data      周工作平台：活动台账、登记表归档

备份 = 复制这两个文件夹。

【注意】
- 包内含真实姓名，只发管理层，勿传大群/公开网盘/代码仓库
- 只在当前这台电脑可用，其他人不能远程访问
- 无需安装 Python、无需联网，已内置运行环境
