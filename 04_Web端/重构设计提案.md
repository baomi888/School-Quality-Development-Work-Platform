# 质检部周工作平台 · 整体重构设计提案

> 整理时间：2026-10-01
> 视角：专业设计师 + 全栈工程师
> 目标：**功能面板重构 + 前端美观度整体升级**，后端逻辑不动。

---

## 一、现状诊断（先找病根，再开药）

当前版本是「奶油薄荷小清新」（`tokens.css` 标注），核心问题不在配色本身，而在**信息架构与视觉语法**：

| # | 问题 | 具体表现 | 影响 |
|---|---|---|---|
| 1 | **页面过长，步骤散落** | 本周工作页从上到下依次是：Hero → 课表 → 六段工作流 → 步骤条 → 步骤1卡片 → 步骤2卡片 → 步骤3卡片 → 步骤4卡片 → 校验 → 预览 → 产物，总高约 3100px | 周四办公时要在长页里上下找当前步骤，眼睛来回跑 |
| 2 | **两套「步骤」并存** | 既有「周一→周日」工作流，又有「1上传→4安排助理」流程条，信息重复且层级不清 | 新人不知道先看哪个 |
| 3 | **状态语义不统一** | 步骤用顶部色条表达、工作流用红/灰、chip 用边框颜色，同一个「当前/完成/待办」概念有多套表达 | 认知负担高 |
| 4 | **多色平铺** | 薄荷绿 + 粉紫 + 蓝 + 橙 + 红同时出现，没有「唯一强调色」纪律 | 视觉没有焦点，显得稚气 |
| 5 | **表格、chip、卡片同质化** | 所有容器都是同一圆角白卡，主次不分 | 信息密度高的表格反而被卡片感稀释 |
| 6 | **反馈靠堆叠 alert** | 成功/警告/错误提示排队出现在内容流里，打断操作节奏 | 操作完要扫一眼多个色块 |
| 7 | **产物散落** | 产物出现在多个步骤卡片里 + 文件列表，无统一出口 | 下载前找不到「本周该发的文件」 |

**工程师视角的存量问题**（`优化迭代建议.md` 已列，重构时一并解决）：
- `Work.tsx` 716 行单体、`styles.css` 678 行单体，未拆分；
- 无路由，三个页面同在主 bundle（仅 Dashboard 懒加载）；
- 无 ErrorBoundary，任一组件崩溃即白屏；
- 无自动化验收门禁，改完只能手动看。

## 二、参考调研结论

### 1. Motion Size（motionsize.app）—— 动效试验场

用户指定参考的落地页，设计语言可归纳为：

- **高对比强排版**：亮黄底 + 近黑大字，超大标题（`Spring animations`），衬线/无衬线大字号，克制的装饰；
- **单一强调色纪律**：整站只有一个彩色（黄），其余全部黑白灰；
- **极简 chrome**：无多余卡片、无堆叠阴影，层级靠字号与留白；
- **灵动微交互**：弹簧动效是灵魂——悬停、切换、数值变化都有「带物理感的轻快反馈」；
- **状态即内容**：交互区本身是主角，控件服务于「调参→看效果」的闭环。

**本项目可借鉴（不是照搬黄底）**：
- 大标题 + 强对比的 hero 排版（已用在方向 A/C）；
- 「一个强调色 + 黑白灰」的色彩纪律（三套方向全部收敛到 1 个品牌色 + 1 个告警色）；
- 微交互的分寸感：chip 选中、步骤切换、卡片悬停要有轻快反馈（方向 B 的弹簧感、方向 C 的发光）。

### 2. GitHub 上「周工作处理 + 数据表格整理分类」类项目

调研了开源生态里最受好评的数据表格/工作流类前端，提炼出共性最佳实践：

| 参考项目 | 可借鉴的设计点 |
|---|---|
| **shadcn/ui 生态后台**（Next Shadcn Dashboard Starter 等） | 白卡片 + 浅灰画布 + 单一品牌色；表格 sticky 表头、行悬停态；状态徽标体系 |
| **AFFiNE**（本地优先知识工作台） | 干净的信息层级、克制配色、大留白；卡片圆角与阴影的分寸 |
| **NocoDB / Baserow / Grist**（开源表格数据库） | 表格是主角而非卡片堆叠；筛选/分类/状态列的可视化表达；空状态引导 |
| **react-weekly-timetable / Schedule-X / cal.com**（周表排期生态） | 周课表的网格化表达；时段/状态用色块而非文字；交互式排期反馈 |
| **Tabler / AdminLTE 新一代**（管理后台模板） | 顶栏 + 左/右栏的工作台布局；常驻侧栏承载次要信息，主区只做当前任务 |

**共性结论（直接落到本项目的四条）**：
1. **工作台布局**：主区只放「当前这一步」，上下文（课表、工作流、产物）常驻侧栏——解决「页面过长」。
2. **表格是主角**：密集信息用规整表格 + 状态徽标，不用卡片套卡片。
3. **单品牌色纪律**：一个主色表达品牌与选中态，一个告警色表达「需要注意」，其余中性。
4. **空状态也是设计**：未上传时给出「下一步做什么」的引导，而不是一句话。

## 三、三套设计方向（已出风格稿，可对比选择）

三套方向**共用同一套新信息架构**（见第四节），只换视觉语法。风格稿均为「第4周 · 官渡/西城 · 3个活动」的真实场景数据。

### 方向 A · 校园编辑部（编辑排版 × 校徽深绿）

- **气质**：正式、权威、像一份装订好的部门文书；Motion Size 的「强对比大排版」用暖纸底 + 墨黑 + 校徽深绿落地。
- **关键手法**：衬线大标题（Noto Serif SC）；零阴影、2px 硬线分区；正红只留给「当前步骤/告警」；表格网格线 + 大写小字表头。
- **适合**：想让工具「像学校部门该有的样子」，稳重耐看、长时间办公不累眼。
- **取舍**：克制感强，视觉惊喜少一些。

### 方向 B · 现代工作台（shadcn/AFFiNE 风 × 灵动微交互）

- **气质**：现代、精致、轻快；当前「小清新」的用户友好度 + 专业后台的信息效率。
- **关键手法**：浅灰画布 + 白卡片 + 深青绿品牌色；圆角/轻阴影/悬停上浮的弹簧感（Motion Size 的「灵动」收敛到交互层）；表格圆角表头、行悬停高亮；步骤条做成带连接线的胶囊进度。
- **适合**：想要「一眼像现代产品」，交互手感最好，也是三套里最稳的折中。
- **取舍**：与市面上多数后台气质相近，个性中等。

### 方向 C · 深色工作坊（Motion Size 深色模式 × 柠檬黄）

- **气质**：酷、有氛围、强个性；直接取材 Motion Size 的深色视觉。
- **关键手法**：近黑画布 + 柠檬黄唯一强调；大字号高对比；当前步骤带发光描边；橙红仅作告警。
- **适合**：喜欢深色工作环境、要「这工具一看就不一样」。
- **取舍**：长时间办公的视觉疲劳风险更高（可做浅色/深色双主题缓解，但深色是主推）。

> 三套方向都可以做**浅色/深色双主题**；方向 C 以深色为主推、方向 A/B 以浅色为主推。

## 四、功能面板重构方案（三套方向共用）

「本周工作」页从**长页堆叠**改为**工作台双栏**：

```
┌──────────────────────────────────────────────────┐
│ 顶栏：品牌(新logo) · 学期 · 导航 · 主题切换 · 构建时间  │
├──────────────────────────────────────────────────┤
│ Hero：周次/校区 kicker + 大标题 + 三个读数(待安排·学院池·进度)│
├──────────────────────────────────────────────────┤
│ 步骤条：1上传 → 2拆分 → 3安排学院 → 4安排助理            │
│   （可点击跳转；完成=✓ / 当前=高亮 / 未到=灰）            │
├──────────────────────┬───────────────────────────┤
│ 主区：只显示「当前步骤」   │ 常驻侧栏（sticky）：          │
│ · 步骤3示例：            │ · 本周活动课表（小）           │
│   规则三格(上周/主办/已选)  │ · 本周工作流 1~6（状态徽标）    │
│   学院池分类选择器          │ · 本周产物（统一下载出口）     │
│   操作按钮 + 结果表格       │                            │
│ · 已完成步骤折叠成摘要      │                            │
│ · 预览/体检在步骤完成后出现   │                            │
└──────────────────────┴───────────────────────────┘
```

**改动清单（逐项）**：

| 项 | 现状 | 改为 | 价值 |
|---|---|---|---|
| 布局 | 单列长页 3100px | 主区 + 常驻侧栏双栏 | 当前步骤永远在首屏 |
| 步骤条 | 纯状态展示 | 可点击跳转 + 连接线 + 三态 | 四步即目录，点哪看哪 |
| 学院池 | 一行流式 chip | 分类网格（可选/已选/上周/主办），配图例 | 一眼分清三种约束 |
| 工作流 | 与步骤条并列的六段长卡 | 收进侧栏变成清单 + 状态徽标 | 消除两套步骤并存 |
| 课表 | 页首大块 | 收进侧栏（可展开） | 主区让位给操作 |
| 产物 | 散落各卡 | 侧栏「本周产物」统一下载 | 一个出口 |
| 反馈 | 堆叠 alert | 顶部/角落 toast，错误详情可展开 | 不打断节奏 |
| 空状态 | 一句话 | 编号引导卡「下一步做什么」 | 新人即开即用 |
| 主题 | 跟随系统 | 手动切换 + 跟随系统 | 演示/弱光环境可控 |
| 工程 | 单体文件/无路由/无边界 | 拆分 hooks/组件、懒加载、ErrorBoundary、verify 门禁 | 改得动、崩不了、可回归 |

## 五、实施计划（确认方向后分阶段执行）

| 阶段 | 内容 | 风险 |
|---|---|---|
| ① 令牌与全局皮肤 | 按选定方向重写 `tokens.css` + 顶栏/Hero/步骤条/卡片/按钮/表格/chip | 低（纯样式） |
| ② 本周工作页重构 | Work 页改双栏工作台：拆 `useWorkflow/usePreview/useDiagnose` + 子组件，步骤切换、侧栏课表/工作流/产物 | 中（需真实 e2e 回归） |
| ③ 首页 + 其余三页换皮 | Hub（Bento 卡片换新）、台账、看板、说明统一视觉 | 低–中 |
| ④ 动效与状态打磨 | 微交互、toast、空状态、深色模式细化、logo 定稿 | 低 |
| ⑤ 工程加固 | 路由懒加载、ErrorBoundary、`npm run verify` 门禁 | 中 |

每阶段交付前用无头浏览器截图前后对比，**你确认一个阶段再进下一个**。

1. **方向**：A 校园编辑部 / B 现代工作台 / C 深色工作坊 —— 你选哪个，或提修改意见（可混搭，如「B 的布局 + A 的配色」）。
