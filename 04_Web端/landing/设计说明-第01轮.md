# 落地页设计说明 · 第 01 轮

> 为「质检部工作自动化」做整体介绍落地页。**用户尚未选定方向** —— 这一轮交付的是三个可比较的设计方向小样，供挑选后深化。

## 一、这一轮要解决什么

**受众**（按优先级）：部门干事（新人要照着上手）→ 老师 → 二级学院质检干部。
**页面任务**：让人快速理解「这套东西替我做了什么、我拿到什么」，并愿意打开工作平台。
**共同内容**：同一套事实、同一套文案骨架，三个方向只在**首屏骨架 / 字体 / 色彩身份 / 主视觉**上拉开差异。

**调性推导**（从题材、受众、场合推出，不套用行业惯例）：

| 刻度 | 取值 | 依据 |
|---|---|---|
| 能量 | 安静偏中 | 行政办公工具，不是营销爆点；但要比现有平台更有主张 |
| 完成度 | 精致、纪律严 | 交付物是 Excel 正式登记表，页面必须显得「靠得住」 |
| 密度 | 疏 | 内容本身不多，靠留白和大字建立分量 |
| 分量 | 重 | 衬线 900 巨字 + 墨色，与"公文/正式"的场合匹配 |
| 严肃度 | 庄重，带一点锋利 | 不用圆角插画那套；锋利感来自字号对比和硬线 |

共同色彩纪律：**暖纸底 + 墨黑 + 单一正红**。红是质检部的身份色（既有的 Web 平台就是这套），也是「机器补上的那一列」的信号色。

## 二、三个方向

### 01 值班室（`D1-值班室.html`）
- **北极星**：像走进质检部的值班室 —— 墙上贴着本周排班，桌上摊着一份刚核完的表，一支红笔在旁边。规整、可信、随时可查。
- **首屏骨架**：通栏上下堆叠。meta 横条 → 巨字标题 → 4 格数据带 → 说明 + **产物缩略图**。
- **色彩身份**：`#F2EFE8` 暖纸 / `#16171A` 墨 / `#B3271E` 砖红（低饱和、公文感）。
- **记忆点**：一学期工作量做成 18 格长度条，每格 = 1 周；红格标高峰。
- **最适合**：要给老师/其他部门看「这活儿有多大」的场合。

### 02 表格主角（`D2-表格主角.html`）
- **北极星**：把交付物本身推上舞台 —— 登记表出血铺满整屏，追加的「安排二级学院检查」列用红底标出来，一眼看清机器到底补了什么。
- **首屏骨架**：左标题 → 满宽出血表格（顶部深色 Excel 文件名栏、底部七项体检勾选条）→ 墨色规则横幅。
- **色彩身份**：`#F3F1EA` / `#15161A` / `#C2352B` 正红 + 荧光绿 `#C9F14E`（只用在「同一份台账」这一处小面积）。
- **记忆点**：红底 + 红左边框的追加列 —— 「这是机器补上的」一句话没说，颜色说了。
- **最适合**：给干事看「我会拿到什么」，实样最有说服力。

### 03 一学期一条线（`D3-一学期一条线.html`）
- **北极星**：一学期就是十八格。每周一格，格子里是这周要跑的事。看得到进度，也就看得到这套东西替谁省了力。
- **首屏骨架**：居中单一物件 —— 巨字标题 + 18 格学期轴，四周大留白；中段切一块深色反差带放四步流程。
- **色彩身份**：`#FAF8F3` / `#101113` / `#CE3226` 朱红 + 一整块深色带。
- **记忆点**：18 格学期轴。四种状态用四种视觉语言区分（已完成为实心柱、本周为红框+浮标、未开始为浅灰、无活动为斜纹），不靠颜色单独承担。
- **最适合**：给新人建立「这套东西覆盖了多少工作量」的心智模型。

## 三、差异检验（已通过）

| 对比 | 骨架 | 字体 | 色彩 | 主视觉 | 结论 |
|---|---|---|---|---|---|
| 01 vs 02 | 不同 | 同（衬线 900） | 不同 | 不同 | **3 项不同，通过** |
| 01 vs 03 | 不同 | 同 | 近似 | 不同 | 2 项不同 —— 这一对最弱，但骨架与主视觉差异足够 |
| 02 vs 03 | 不同 | 同 | 不同 | 不同 | **3 项不同，通过** |

眯眼看首屏明暗块面：01 = 上重下空；02 = 中间一条极宽的表格；03 = 上下重、中间空。**三版块面分布不相似**，不存在「名为不同、实际雷同」。

已避开的品类套路：不用「大标题 + 特性三宫格 + 用户评价 + CTA」那套；**没有一版使用左右分栏**；三宫格用的是不等宽 `1.5fr 1fr 1fr` / `1.35fr 1fr 1fr` 且三格内容不同质。

## 五、视觉验收（已实测，非声称）

| 检查项 | 方法 | 结果 |
|---|---|---|
| 横向溢出 | Puppeteer 遍历全部元素比对 `documentElement.clientWidth` | 6/6 视口通过 |
| 对比度 | 遍历渲染后文字节点按 WCAG 计算 | 关键项全部达标（正文 ≥5.07:1） |
| 字体真实可用 | `--glyph-names=no` 子集后实测渲染 | 5 个字重，均为本地 woff2 |
| 离线可用 | 扫描全部 `href`/`src` | **零外链**，无 CDN 依赖 |
| 对比页功能 | 并排 / 单张 / 桌面手机切换 / 选择 | 均可用，无控制台错误 |

## 六、离线字体方案（重要）

落地页要求「无需联网」，而中文字体不能整包引入。做法：

1. **源**：本机 Windows 自带的 `NotoSansSC-VF.ttf` / `NotoSerifSC-VF.ttf`（可变字体）。
2. **取字重**：用 `fontTools.varLib.instancer` 从可变字体实例化出 400/500/700/900 四个字重。
3. **子集化**：按三个候选 + manifest 的**实际用字**（618–656 字）裁切，`--glyph-names=no`（Google/系统分片无 post 表）。
4. **产出**：5 个 woff2，合计约 **567 KB**（整包要 8–10 MB/字重）。
5. **同步**：`tools/subset_fonts.py` 生成 → 内联进各候选 `<style>`（对比页生成器只内嵌资源文件、不认外部 CSS `<link>`）。

> 改动候选文案后**必须重跑** `tools/subset_fonts.py`，否则新出现的字会回退到系统字体。

## 八、选定后怎么继续

1. 在对比页里选一个方向，点「选择」复制那句话发我（带上你具体喜欢/不喜欢哪里）。
2. 我把它做成正式落地页：补真实截图/数据、做独立评审第二轮、按需加交互。
3. 挂到引擎上：作为 `/` 或 `/landing` 由 FastAPI 托管（**零构建，不用 Vite**），改完刷新即见。
